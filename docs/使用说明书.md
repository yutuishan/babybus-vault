## 一、这个软件是做什么的

**宝宝巴士是一个"加密文件保险箱"。** 你把文件放进去，硬盘上留下的就只是一堆乱码；
只有输入你设的主密码，才能把它们重新打开。

它适合放这类东西：身份证件扫描件、合同、财务资料、私密照片、工作底稿。

它有三个特点，也是它和你熟悉的网盘/压缩包不一样的地方：

| | 说明 |
| --- | --- |
| **纯本地** | 文件只存在你自己的电脑上，不上传任何服务器 |
| **不联网** | 软件运行时不访问网络，没有账号、没有同步、没有云端备份 |
| **明文不落盘** | 打开文件时，内容只在内存里解密，不会在硬盘上产生一个"临时明文副本" |

> **它不是杀毒软件，也不防木马。** 它防的是"电脑丢了/被人拿走/硬盘被翻"这类情况。
> 如果你的电脑已经中了木马，木马可以像你一样打开文件。

## 二、第一次使用：创建文件库

"文件库"就是存放你所有加密文件的那个文件夹。第一次用要先建一个。

1. 打开软件，点击 **新建文件库**
2. **选择一个位置**。建议：
   - 放在**非系统盘**（比如 D 盘），换系统重装时不容易被误删
   - 留足空间 —— 放进去的文件会占用和原文件差不多的体积
   - **不要**放在会被云盘自动同步的目录里（同步会把你所有密文传上去，没必要，也慢）
3. **设置主密码**。要求：
   - 至少 8 位
   - 包含字母
   - 包含数字

   > 建议用一句只有你记得的话 + 数字，比如 `lanTian2026Yun`。别用生日、手机号、`123456`。

4. **填写密码提示（可选，但强烈建议）**
   提示会显示在**锁屏界面和输入密码时**，帮你回忆。
   ⚠️ **提示语是以明文保存的** —— 任何拿到这个文件夹的人都能直接读出来。
   所以请写成"只有你自己看得懂的线索"（例如「老家那棵树 + 年份」），**千万不要把密码本身写进去**。

5. 点 **创建**。稍等一两秒（密码加密本身是故意设计成"慢"的，这是安全性的来源）。

**创建完成后，你只会看到一个空文件库。** 接下来就可以导入了。

> ### ⚠️ 请务必记住主密码
> 软件**没有任何找回密码的功能**，也没有"后门"或"客服能帮你解开"。
> 忘记主密码 = 文件永久无法打开。这不是缺陷，而正是它安全的原因 ——
> 如果存在一条能绕过密码的路，那这条路也能被别人走。

## 三、日常使用

### 界面分区

```
┌─────────────────────────────────────────────────────────┐
│  工具栏：导入 ▾  导出  新建文件夹  删除  刷新   搜索    │
│          文件库  新手引导  设置  锁定                    │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│   文件库      │            预览区                        │
│  （目录树）   │      （选中文件后在这里查看内容）          │
│              │                                          │
├──────────────┴──────────────────────────────────────────┤
│ 状态栏：文件数 · 总大小 · 加密算法 · 库位置 · 锁定倒计时  │
└─────────────────────────────────────────────────────────┘
```

### 解锁与锁定

- **打开软件**：输入主密码。锁屏界面会显示你设置的密码提示。
- **手动锁定**：点右上角 **锁定**。锁定后立即清空内存里的密钥，正在预览的内容也会被清掉。
- **自动锁定**：一段时间没有操作就自动锁上。可选 **1 / 5 / 15 / 30 分钟 / 1 小时**。
  > 这里**没有"从不"这一档**，是有意为之 —— 人离开电脑时往往不会记得手动锁定。
- **系统休眠/睡眠时自动锁定**：默认开启，可在设置里关掉。

### 导入文件

点工具栏的 **导入 ▾**，有两个选项：

- **导入文件…** —— 可以一次选多个文件
- **导入文件夹…** —— 整个文件夹一起进来，**子文件夹的层级会原样保留**

关于落在哪：

| 导入方式 | 落在哪里 |
| --- | --- |
| 工具栏「导入」（选文件） | **一律放在根目录** |
| 工具栏「导入」（选文件夹） | 根目录下建一个同名文件夹，里面的结构照搬 |
| **拖拽**文件到某个文件夹上 | 落在那个文件夹里 |

> 小提示：导入文件夹时，**文件夹本身也会被建出来**。如果你希望里面的文件直接落在根目录，
> 请用「导入文件」逐个选，或者导入后再把它们拖出来。

**遇到重名怎么办？** 软件会先列出一个冲突清单，然后让你选：

- **保留两者**（默认）—— 新来的自动改名成 `名字 (2)`，两份都在，**不会丢东西**
- **覆盖** —— 用新的替换旧的，旧的那份会被删除

> 如果你不确定，就选「保留两者」。

**导入有个上限**：单个文件超过 **256MB** 会被跳过（会在清单里提前告诉你）。

### 整理文件

- **多选**：按住 `Ctrl` 逐个点选，或按住 `Shift` 连选一片
- **拖动移动**：按住拖动即可。**多选之后拖动，会整批一起移动**，
  拖动时会跟着光标显示「移动 N 项」。
  > 不能把文件夹拖进它自己或它自己的子目录里 —— 那会让整个子树从目录树上掉下来，软件会拦住并提示你。
- **重命名**：双击文件名，改完按回车（按 `Esc` 取消）
- **右键菜单**：重命名 / 新建文件夹 / 导出 / 删除
- **删除**：选中后点工具栏的「删除」。文件夹会连里面的东西一起删，请确认后再操作。
- **刷新**：如果你用别的程序改动过文件库文件夹，点「刷新」重新读一次。
- **收起/展开**：工具栏左侧的按钮可以把文件库面板收起来，给预览区让出更多空间。

### 预览

点左侧的文件，右边就会显示内容。**支持直接查看的格式：**

| 类型 | 格式 |
| --- | --- |
| 文档 | PDF、Word（docx）、旧版 Word（doc，只能看文字） |
| 表格 | Excel（xlsx / xls，多工作表可切换） |
| 演示 | PowerPoint（pptx） |
| 文本 | txt、md、json、xml、yml、log、csv 等 |
| 图片 | png、jpg、gif、webp、svg、bmp 等 |
| 音频 | mp3、wav、flac、aac、ogg、m4a 等 |
| 视频 | mp4、webm、mov、mkv、avi 等 |

**音频和视频是"边解密边播放"的** —— 可以随意拖动进度条，内存占用和文件大小无关，
几百 MB 的视频也不会卡死。

> 出于安全考虑，播放器**没有下载按钮**，也不能投屏 ——
> 投屏会把解密后的内容送到外部设备，与"明文不外流"冲突。需要拿走文件请用「导出」。

**超过 32MB 的文档、表格、演示文件不能预览**（会提示"可导出后查看"）。
这是为了避免把大文件整份读进内存。音视频不受这个限制。

### 搜索

顶部搜索框可以搜**文件名**，也能搜**文本类文件的内容**（txt / md / json / csv 等）。
按 `Esc` 清空。

### 导出

1. 选中要导出的文件或文件夹（可多选）
2. 点 **导出**
3. 选一个目标文件夹

导出的文件会**保持原来的目录结构**，文件名也原样。

> ⚠️ **导出后的文件不再受保护** —— 它们是普通的明文文件，任何能访问那个目录的人都能打开。
> 请把导出目录选在安全的位置，用完记得删除。

## 四、设置

点工具栏的 **设置**，分两个页签。

### 常规

| 项目 | 选项 | 说明 |
| --- | --- | --- |
| **主题** | 亮色 / 暗色 | 默认亮色 |
| **字体大小** | 小 / 标准 / 大 / 特大 | 屏幕小或者眼睛累的时候调大 |
| **自动锁屏** | 1 / 5 / 15 / 30 分钟 / 1 小时 | 无操作多久后自动锁定 |
| **系统休眠或睡眠时自动锁定** | 开 / 关 | 默认开 |

页面底部还会显示当前文件数和软件版本。

### 主密码

- **修改主密码**：需要先输入原密码。改密码**不会重新加密你的文件**，只是换了一把"开锁的钥匙"，所以很快，文件也不会变。
- **密码提示**：随时可以改。清空即删除。

> 改密码前请确认新密码记得住 —— 改完如果忘了新密码，数据同样无法恢复。

## 五、必须知道的几件事

1. **忘记主密码 = 数据永久丢失。** 没有找回功能、没有后门、没有云端备份。
2. **密码提示是明文保存的。** 不要直接把密码写进提示里。
3. **导出的文件是明文。** 导出后就不受保护了。
4. **文件库文件夹要定期备份。** 硬盘坏了、误删了，软件本身救不回来。
5. **软件不联网。** 它不会上传任何东西，也不会自动更新。

## 六、备份与换电脑

### 备份

**直接把整个文件库文件夹复制走就行** —— 复制到移动硬盘、另一块盘，或者任何你信得过的地方。
文件夹里是加密后的内容，别人拿到也打不开。

建议定期做（比如每月一次）。文件库里的东西越多，越值得备份。

### 换电脑 / 重装系统

1. 在新电脑上装好软件
2. 把整个文件库文件夹拷过去
3. 打开软件 → **打开文件库** → 选中那个文件夹
4. 输入主密码

不需要任何"导入导出"操作，也不需要联网。

### 绿色版的好处（Windows）

Windows 绿色版把配置存在**程序所在目录**。也就是说你可以把整个程序文件夹（含 `config.json`）
拷到 U 盘里，插到别的电脑上直接用，配置也跟着走。

> macOS 版不会往 `.app` 里写东西（那会破坏应用包），配置放在系统的
> `~/Library/Application Support/宝宝巴士`。

## 七、常见问题

**Q：我忘记主密码了，还有救吗？**
A：没有。这是设计上的取舍 —— 能绕过密码的路，别人也能走。请把密码写在只有你能拿到的地方
（比如纸质笔记本），或者用一个你绝对不会忘的句子。

**Q：为什么有些文件不能预览？**
A：分几种情况：
- **超过 32MB 的文档/表格/演示** —— 会提示"可导出后查看"。音视频不受此限。
- **ppt / odt / ods / odp** —— 这些格式暂不支持预览，导出后用 Office / WPS 打开。
- **旧版 doc（Word 97-2003）** —— 只能看到文字，看不到排版和图片。这是格式本身的老旧所致。

**Q：视频提示"当前内核解不了这个编码"，怎么办？**
A：这种情况通常是**容器里装了不常见的编码**（典型是 mkv 里装 H.265）。
软件只看扩展名，判断不了内部编码。请**导出后用本地播放器**（如 VLC、PotPlayer）打开。
如果 mp4 / mp3 这类标准格式也报这个错，请点「刷新」后重试，或联系技术支持。

**Q：我导入的文件去哪了？**
A：工具栏「导入」一律放在**根目录**。如果没看到，点一下文件库最上面的根节点，或者用搜索框找文件名。

**Q：导入时选了「覆盖」，能撤回吗？**
A：不能，旧的那份已经被删除。所以默认选项是「保留两者」。

**Q：为什么自动锁定没有「从不」？**
A：因为人离开电脑时经常忘记手动锁定，而"忘记锁"的代价远大于"多输一次密码"。

**Q：软件会联网吗？会不会偷偷上传我的文件？**
A：不会。软件运行时没有任何网络请求，也没有账号体系。你可以用防火墙把它完全断网，
功能不受影响。

**Q：卸载软件会删掉我的文件吗？**
A：不会。文件库是一个普通文件夹，卸载程序不会碰它。你的文件还在，装回软件就能继续用。

**Q：能在手机上用吗？**
A：目前只有 Windows 和 macOS 桌面版。

**Q：文件库能放在移动硬盘或 U 盘上吗？**
A：可以，直接把库文件夹放在移动硬盘上即可。注意两点：① 用完要安全弹出，
避免写入中断导致库损坏；② 别同时在两台电脑上打开同一个库。

**Q：能同时打开两个文件库吗？**
A：可以打开不同的库，但同一个库不要在两台电脑上同时用。

## 八、功能限制

| 限制 | 数值 / 说明 |
| --- | --- |
| 单个文件导入上限 | **256MB**（超过会跳过并在清单里提示） |
| 文档预览上限 | **32MB**（音视频不受限，走流式解密） |
| 不支持的预览格式 | ppt、odt、ods、odp |
| 旧版 doc | 仅提取文字 |
| 文件名长度 | 受操作系统限制（Windows 路径约 260 字符） |
| macOS 版签名 | **未签名**。首次打开需「右键 → 打开」，或执行 `xattr -dr com.apple.quarantine <App路径>` |

## 九、文件都放在哪

### 你的文件库

就是创建时你选的那个文件夹。里面长这样：

```
你的文件库/
├── vault.meta          # 加密参数、密码校验值、密码提示（提示是明文的）
├── manifest.enc        # 加密的目录结构（文件名、层级都在里面）
├── manifest.enc.bak    # 上一版备份
└── blobs/
    ├── 3f2a….enc       # 每个文件一份密文，文件名是随机 id
    └── 91b7….enc
```

**注意看 `blobs/` 里那些文件名** —— 全是随机编号，看不出任何内容；
真实的文件名只存在于加密的 `manifest.enc` 里。所以就算别人翻到这个文件夹，
他也**看不到你有哪些文件、叫什么名字**。

> `vault.meta` 是**明文**的，里面只有加密参数和你的密码提示。
> 这就是为什么提示语不能写密码。

### 软件配置

| 平台 | 位置 |
| --- | --- |
| Windows 绿色版 | 程序所在目录的 `config.json` |
| Windows 安装版 / 无写入权限时 | `%APPDATA%\宝宝巴士\config.json` |
| macOS | `~/Library/Application Support/宝宝巴士/config.json` |

配置里只有主题、字号、自动锁屏时间这些偏好设置，**不含任何文件内容或密码**。

## 需要帮助？

遇到问题请提供以下信息，便于快速定位：

1. 软件版本（设置 → 常规 页面底部）
2. 操作系统版本
3. 具体操作步骤和看到的提示文字（**截图最好**）
4. 如果是某个文件出问题：它的**扩展名和大小**

> ⚠️ **请不要把主密码告诉任何人**，包括技术支持。没有任何正当理由需要知道你的密码。
